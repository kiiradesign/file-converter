# File Converter

Vite + React + TypeScript canvas UI for converting files in the browser.
Same UI is designed to wrap in Tauri as a Mac app later.

## Develop

```bash
npm install
npm run dev
```

## Milestone 1 (browser)

- Infinite dotted canvas with file/folder nodes
- PNG ↔ JPG ↔ WEBP conversion (quality + resolution)
- Folder drill-in, Adjust chain, Save / zip download
- No server uploads — all conversion runs in-tab
